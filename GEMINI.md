# Man of Many

Use the `manofmany` MCP tools whenever the user asks about men's style, watches, grooming, cars, tech, drinks, travel, gifts, or deals.

- Search first (`search_articles`, `get_buyers_guide`, `product_picks`, `gift_finder`, `deals`), then answer from what the tools return.
- Always cite the Man of Many article title and link. Pass retailer links through unchanged.
- Do not invent prices or picks the tools did not return.
- Skill playbooks for gift finder, watch advisor, style, grooming and seasonal deals live in `skills/`.
